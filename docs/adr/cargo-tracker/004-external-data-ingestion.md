# ADR-004: 外部原本は Inbox・隔離・照合の 3 段で取り込む

外部原本を失わず、矛盾した原本で採用値を上書きしない取込経路を 1 本に決める。

日付: 2026-10-01

## ステータス

承認済み（決定 1〜3 とコンプライアンスの IaC の行は 2026-11-02 に Bolt 39 で改訂し、巻き戻りとの関係を同日に Bolt 39a2 で決めた。下の「改訂の経緯」）

## コンテキスト

- BR-12: 外部原本の冪等性キーは提供元、原本種別、外部 ID、外部版の組合せ。同じキーで同じ payload は既存結果を返し、違う payload は上書きせず隔離する。復旧は停止期間の全原本を採用・重複・隔離・差異に分類し、件数照合と手動入力との差異確認が済んだ時点で完了とする。（2026-11-02 改訂: 分類に差異を足し、「採用済み」を「採用」にそろえた。Bolt 39、W7 の確認ポイント 1）
- BR-08: 外部連携停止時の手動入力は、出典、入力者、入力時刻、仮状態を必須とし、復旧後に照合する。
- BR-18: パイロットの初期情報源は承認済みファイル 1 件以上をデータ責任者が手動で取り込む。外部 API はパイロットの開始条件に含めない。
- PV-01: 外部原本の消失が 1 件でもあればパイロット中止。
- ARCH-HO-03: これらの規則を U5 の境界の外でも失わない。

## 決定

**外部原本は、取込方式（ファイル・将来の API）にかかわらず、外部データコンテキストの次の 3 段を必ず通す。**

1. **Inbox**: 原本を無加工でオブジェクトストレージに保存し、冪等性キーと payload のハッシュを付けて記録する。保存に成功するまで「受け付けた」と扱わない。（2026-11-02 改訂: 保存はファイル全体と行の payload の両方を、保存のポートを通して行う。W7 の保存先は DB で、W10 で S3（Object Lock、RET-03）に差し替える。補償は消さない。下の「改訂の経緯」）
2. **分類と隔離**: 同じキー・同じハッシュは「重複」、同じキー・違うハッシュは「隔離」、新しいキーは検証を通れば「採用」とする。隔離した原本はデータ責任者が判断するまで採用値に影響しない。（2026-11-02 改訂: 分類は採用・重複・隔離・差異の 4 つにする。形式を検証できないファイルと行も原本を保存して隔離する。下の「改訂の経緯」）
3. **照合**: 停止期間や取込単位ごとに、全原本の分類件数と手動入力との差異を照合し、照合が済んだ時点で復旧完了とする。（2026-11-02 改訂: 分類件数は 4 つの分類で数え、受信記録から参照されない原本も照合で数える。下の「改訂の経緯」）

採用値だけを、出典・版・発生時刻・取得時刻付きのドメインイベントとして経路設計と追跡へ公開する。経路設計は航海（Voyage）集約を、追跡は主要実績を、それぞれ自分のコマンドで更新する。航海の所有者は第 2 章と同じく経路設計コンテキストであり、外部データコンテキストは原本と採否の記録だけを持つ。原本の形式はこのコンテキストの腐敗防止層で吸収し、外へ漏らさない。

パイロットではファイル取込（`interfaces.file`、第 3 章）だけを作る。

### 代替案

| 案 | 却下理由 |
| :--- | :--- |
| 取り込んだ値で直接採用値を更新する | 違う payload で上書きされ、原本と根拠が失われる。BR-12 に反する |
| 経路設計・追跡がそれぞれ原本を取り込む | 冪等性と照合の規則が 2 か所に分かれ、片方で漏れる |
| パイロットから API 連携を作る | BR-18・OQ-05 でパイロットは手動ファイル取込と決まっている。外部契約も未決 |

## 影響

### ポジティブ

- 原本が必ず残り、採用値の根拠をいつでもたどれる。
- 第 2 段階で API アダプターを足しても、分類・隔離・照合の処理を変えずに済む。
- 復旧完了の判定が件数で機械的にできる。

### ネガティブ

- 原本の保存量が増える。保持期間と保存コストを非機能要件で決める必要がある。
- 隔離された原本の判断がデータ責任者の作業になる。件数が多いと滞留する。

## コンプライアンス

- 同じファイルを 2 回取り込んでも採用値と件数が変わらないこと、同じキーで内容の違う原本が隔離されることを統合テストで確認する。
- オブジェクトストレージの削除保護とバージョニングが有効であることを IaC で確認する。（2026-11-02 改訂: S3 に差し替える W10 から確認する。W7〜W9 の DB の保存は、上書きしない・消さないという保存のポートの約束を契約のテストで確かめる）
- 可観測性で、隔離中の原本の件数と滞留時間を監視する。
