## 総合評価

本番の成果物に H2 を入れない約束（ADR-007、AT-06）を守ったまま dev のデモを動かす構成（bootJar を変えず、`copyDemoLibs` と `demo` のステージで H2 だけを足す）は、3 つの視点のどれからも評価された。`runtime` のイメージが dev で落ちることを失敗の側から確かめたこと、R14 を計測して `-Xmx300m` に固定したこと、取り消せない削除をタスクにしなかったこと、つまずきを手順書に残したことも評価された。

一方で、リポジトリと GitHub Pages が公開のため「URL は関係者にだけ伝える」が成り立たないこと、ADR と計画が旧いタスク名（`heroku:*`）のままで実装と食い違うこと、配備のガードがブランチを見ず `build` にしかないこと、動いているコミットが分からないこと、ロールバックの手順がないことが指摘された。`runtime` のステージに Heroku の都合（`PORT`・`sh -c`・`EXTRA_CLASSPATH`）が混ざっていて、W10 の ECS の出発点としては分け直しが要ることも指摘された。
