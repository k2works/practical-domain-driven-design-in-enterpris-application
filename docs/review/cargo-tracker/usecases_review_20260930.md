## 改善アクション

1. H-01 の業務判断を行い、予約・経路・見積りの状態と用語を全成果物で統一する。
2. OQ-03〜OQ-07 を decision table へ分解し、未決のストーリーを `blocked` としてゲート 4 の完了チェックを再評価する。
3. 状態遷移表、時刻境界、外部原本・復旧の test oracle を追加する。
4. 有人引継ぎ、異常時の次アクション、荷受人の案件別参照許可をストーリー化する。
5. Must の再選別、ストーリー分割、薄いウォーキングスケルトンを行う。
6. トレーサビリティ表を修正し、前方・後方の機械検査を追加する。
7. 横断 UX・アクセシビリティ最低保証と、後続のアーキテクチャ・非機能要件・テスト戦略への引継ぎ表を追加する。
8. 高重要度の修正後、5 視点の差分レビューを行ってゲート 4 を再判定する。
