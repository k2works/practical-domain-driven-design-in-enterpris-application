# 13 章 有人案件

顧客からの照会や、自動の処理では扱えない例外を、担当者が受け付けて対応する案件を「有人案件」と呼びます。本章は、有人案件を一覧で確かめ、詳細を開いて受領し、進捗の更新・回答の記録・終結・再開まで進める画面を説明します。

画面の開き方: ナビゲーションの「有人案件」（URL: `/staff/service-cases`）。カスタマーサポート・営業担当者・経路設計者・追跡管理者・データ責任者が使えます。システム管理者・監査担当者・荷主担当者には開けません（権限がない画面と同じ表示になります）。

| 画面 | 役割 | 節 |
| :--- | :--- | :--- |
| 有人案件の一覧 | 未終結・未受領・期限超過・対応中の案件を、受領期限の古い順に確かめる | [13.1](#131-有人案件の一覧) |
| 有人案件の詳細 | 受付から対応の状況までを確かめ、受領する | [13.2](#132-有人案件の詳細と受領) |
| 照会の記録 | 電話・メールで受けた照会を記録し、必要なら有人案件へ引き継ぐ（カスタマーサポート） | [13.3](#133-照会の記録) |

## 13.1 有人案件の一覧

### この画面でできること

- 有人案件を、受領期限の古い順に確かめます。受領期限の近い案件から対応できます
- 「未終結」「未受領」「期限超過」「対応中」で絞り込みます
- 受付番号をクリックして、詳細を開きます

### 画面の開き方

- ナビゲーションの「有人案件」（URL: `/staff/service-cases`）

### 画面の説明

| # | 項目 | 説明 |
| :--- | :--- | :--- |
| ① | 絞り込み | 「未終結」（初めに開いたとき。受付済み・上位対応中・対応中・回答済み）、「未受領」（受付済み・上位対応中）、「期限超過」（受領期限を過ぎた案件）、「対応中」。選んでいる絞り込みは強調されます |
| ② | 受付番号 | 例: SC-2026-0057。クリックすると詳細が開きます |
| ③ | 種類 | 顧客照会、見積り相談、変更・取消し、経路の再設計、外部停止、拒否した実績、予約サガの失敗 |
| ④ | 優先度 | 高または通常 |
| ⑤ | 担当部門 | 案件を扱う部門 |
| ⑥ | 状態 | 受付済み、上位対応中、対応中、回答済み。受領期限を過ぎた受付済みには、印（⚠）の付いた「期限超過」が並びます |
| ⑦ | 受領期限 | 日本時間と UTC を併記します |

### 操作手順

1. 見たい絞り込みをクリックします
2. 対応する案件の受付番号をクリックします

### 注意・補足

- 「期限超過」は、画面を開いたときの時刻で判定します。受領期限を過ぎた受付済みの案件が対象で、状態そのものは変わりません（状態を自動で上位対応中にする処理と、上位の運用責任者への通知は、これから追加します）
- 一覧は受領期限の古い 200 件までです。超えるときは「受領期限の古い 200 件だけを示しています。」と示されます
- 案件がないときは、絞り込みごとに「未終結の有人案件はありません。」「期限超過の案件はありません。」などと示されます

## 13.2 有人案件の詳細と受領

### この画面でできること

- 案件の種類・状態・担当・受領期限・回答期限・次回更新を確かめます
- 進捗と回答の履歴を確かめます
- 受付済みまたは上位対応中の案件を受領します（担当者になり、案件は対応中になります）

### 画面の開き方

- 有人案件の一覧で受付番号をクリックします

### 画面の説明

| # | 項目 | 説明 |
| :--- | :--- | :--- |
| ① | 種類・優先度・担当部門・内容 | 受け付けた案件の内容 |
| ② | 状態 | 受付済み、上位対応中、対応中、回答済み、終結、重複終了。受領期限を過ぎた受付済みには「期限超過」が並びます |
| ③ | 担当・受領時刻 | 受領する前は「まだ受領されていません」と「なし」。受領すると、受領した人（自分なら「あなた」）と時刻が示されます |
| ④ | 受領期限・回答期限・次回更新 | 日本時間と UTC を併記します |
| ⑤ | 復旧照合 | 外部停止の案件だけに示されます。「未完了」または「完了」 |
| ⑥ | 「SC-… を受領する」 | 受付済みまたは上位対応中の案件だけに示されます |
| ⑦ | 進捗・回答 | 記録された順に示されます。まだなければ「進捗はまだありません。」「回答はまだありません。」 |

### 操作手順

1. 一覧で対応する案件の受付番号をクリックして、詳細を開きます
2. 「SC-… を受領する」をクリックします
3. 「SC-… を受領しました。対応中にしました。」と示され、担当があなたになります

#### 受領した後の操作

案件の状態によって、詳細に出る操作が変わります。

| 状態 | 出る操作 | 結果 |
| :--- | :--- | :--- |
| 対応中 | 「進捗を更新する」（進捗の内容。次回更新日時は日本時間で `2026-11-16 18:00` の形。空なら変えません） | 「進捗を更新しました。」。進捗の履歴に追記され、次回更新日時を入れたときは「次回更新」が変わります |
| 対応中 | 「回答を記録する」（回答の内容） | 「回答を記録しました。回答済みにしました。」。状態が回答済みになります |
| 回答済み | 「SC-… を終結する」 | 「終結しました。」。状態が終結になります |
| 終結 | 「SC-… を再開する」（顧客の回答。未解決の内容） | 「再開しました。対応中にしました。」。受付番号・進捗・過去の回答はそのままで、顧客の回答が最後の回答に記録されます |

- 外部停止などの復旧照合が必要な案件は、照合が完了するまで終結できません。「復旧照合が完了していないため、終結できません。」と示されます
- 内容が空のとき、できない状態のとき（ほかの人が先に操作したときなど）、競合したときは、警告が示されます。最新の状態を確かめてから、もう一度操作してください
- 状態が「上位対応中」の案件には、「受領期限を過ぎたため、上位の運用責任者へ回しています。」と示されます。受領すると対応中になります

### 注意・補足

- 受領できるのは、受付済みと上位対応中の案件だけです。ほかの人が先に受領していたときは、「この案件は受領できる状態ではありません（今の状態: 対応中）。最新の状態を確かめてください。」と示されます
- ほかの人の更新が先に保存されたときは、「ほかの更新が先にこの案件を変更しました。最新の状態を確かめ、必要なら、もう一度受領してください。」と示されます。画面を開き直して確かめてから、もう一度操作してください
- 担当者の表示名は、今のところ自分以外は利用者 ID で示されます
- 存在しない受付番号を開くと、ページが見つからない画面（404）になります

## 13.3 照会の記録

### この画面でできること

- 電話・メールで受けた顧客の照会を記録します。引継ぎが不要な照会も記録します
- 回答に必要な情報が確認中などで担当部門へ引き継ぐときは、有人案件として起票し、受付番号を発行します
- この画面を使えるのはカスタマーサポートだけです

### 画面の開き方

- ナビゲーションの「照会の記録」（URL: `/staff/inquiries/new`）

### 画面の説明

| # | 項目 | 説明 |
| :--- | :--- | :--- |
| ① | 経路 | 電話またはメール。初めは何も選ばれていません |
| ② | 追跡番号 | 照会を受けた貨物の追跡番号。荷主企業は追跡記録から決まります。あなたの担当企業の追跡記録だけを指定できます |
| ③ | 照会者の種別 | 荷主または荷受人 |
| ④ | 受付時刻（日本時間） | 例: 2026-11-16 10:30。空なら記録した時刻になります。今より後の時刻は入れられません |
| ⑤ | 照会内容 | 4000 文字まで。引き継ぐときは必須で、有人案件の内容になります |
| ⑥ | 参照した出典（任意） | 回答のために参照した記録の番号など。引き継ぐと有人案件の出典になります |
| ⑦ | 担当部門 | 引き継ぐときの担当部門。空なら CS になります |
| ⑧ | 有人案件へ引き継ぐ | チェックすると、有人案件を起票して受付番号を発行します |

### 操作手順

1. 経路・追跡番号・照会者の種別を入れます
2. 引き継ぐときは、照会内容を入れ、必要なら参照した出典と担当部門を入れて、「有人案件へ引き継ぐ」にチェックします
3. 「記録する」をクリックします
4. 引き継がないときは「照会を記録しました。」と示されます。引き継いだときは「照会を記録し、有人案件 SC-… として引き継ぎました。回答期限は …、次回更新は … です。」と示され、「有人案件 SC-… を開く」から詳細（[13.2](#132-有人案件の詳細と受領)）を開けます

### 注意・補足

- 追跡番号の追跡記録がない、または担当企業の範囲の外のときは、どちらも「この追跡番号の追跡記録は見つかりません」と示されます
- 同じ内容で未終結の有人案件がすでにあるときは、新しく起票せず、その案件に引き継ぎます（「…があるため、その案件に引き継ぎました。」）
- 引き継ぐのに照会内容が空のときは、「照会内容: 引き継ぐときは入力してください」と示され、何も記録されません
- 営業カレンダーが登録されていないときは、期限を計算できないので、「営業カレンダーが登録されていないため、有人案件へ引き継げません。」と示され、何も記録されません。システムの運用担当に連絡してください
- 記録した照会の一覧は、この画面にはまだありません（KPI の集計は今後追加します）
