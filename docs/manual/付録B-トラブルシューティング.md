# 付録 B トラブルシューティング

困ったときの症状から引く Q&A です。画面に出たメッセージで探してください。

## 1. ログインと画面

### Q1-1. ログインできない（「メールアドレスまたは password が正しくありません。」）

| 確認すること | 対処 |
| :--- | :--- |
| メールアドレスと password を正しく入れたか | 入れ直してください。どちらが違うかは画面に示されません |
| それでもログインできない | 荷主の方は担当営業に、社内の方はシステム管理者にお問い合わせください |

### Q1-2. 「もう一度ログインしてください」と示された

| 確認すること | 対処 |
| :--- | :--- |
| 30 分以上操作がなかった、またはログインから 8 時間を過ぎた | 仕様です（不具合ではありません）。「ログインへ」からログインし直すと、開いていた画面に戻ります。送信していない入力は保存されていないので、入れ直してください |

### Q1-3. 「権限がありません」と示された

| 確認すること | 対処 |
| :--- | :--- |
| 役割にない画面（荷主の方が社内の画面など）を開いた | 仕様です（不具合ではありません）。「ホームへ戻る」で戻ってください |
| 自分の役割で使う画面のはずなのに示される | 荷主の方は担当営業に、社内の方はシステム管理者にお問い合わせください |

### Q1-4. 「この画面は準備中です」と示された

| 確認すること | 対処 |
| :--- | :--- |
| ナビゲーションの「問い合わせ」「通知」を開いた | 仕様です（不具合ではありません）。まだ作っていない画面です。使えるようになるまでは、担当営業にご連絡ください |

## 2. 荷主の画面

### Q2-1. 見積依頼を提出できない（「入力内容に N 件の誤りがあります」）

画面の上の誤りの一覧の項目をクリックすると、その入力欄に移ります。主なメッセージと対処は [エラーメッセージ早見表](#4-エラーメッセージ早見表) を見てください。

### Q2-2. 危険物・冷凍の貨物を依頼したい（「危険物・冷凍・その他特殊の貨物は、この画面では受け付けていません。担当の営業窓口へご相談ください」）

| 確認すること | 対処 |
| :--- | :--- |
| 貨物種別で「危険物」「冷凍」「その他特殊」を選んだ | 仕様です（不具合ではありません）。担当の営業窓口へご相談ください |

### Q2-3. 見積依頼の詳細に確定した経路が出ない

| 確認すること | 対処 |
| :--- | :--- |
| 状態が「経路設計中（A 社の対応待ち）」か | 仕様です（不具合ではありません）。経路設計者が経路を設計しています。承認の準備ができたら担当営業からご連絡します。確定すると「見積りと経路の承認待ち（お客様の対応待ち）」になります |

### Q2-4. 予約一覧の追跡番号がクリックできない（「追跡の開始待ち」）

| 確認すること | 対処 |
| :--- | :--- |
| 本予約が確定した直後か | 仕様です（不具合ではありません）。追跡の開始を待っています。しばらくして画面を開き直すと「追跡中」に変わり、クリックできるようになります |
| 「追跡の開始待ち（担当営業が確認します）」と示される | 担当営業が状況を確かめています。しばらく待っても変わらなければ、業務番号を添えて担当営業にご連絡ください |

### Q2-5. 追跡番号で照会すると「追跡番号が見つかりません」と示される

| 確認すること | 対処 |
| :--- | :--- |
| 追跡番号に誤りがないか | CT で始まる 14 文字です。英字の I・L・O と数字の 0・1 は使いません |
| 自社の貨物の追跡番号か | 仕様です（不具合ではありません）。自社の貨物でない追跡番号は照会できません |
| 予約の確定の直後か | 追跡の開始が終わるまで照会できません。予約一覧で「追跡中」になってから照会してください |

## 3. 社内の画面

### Q3-1. 本予約を確定できない

| メッセージ | 対処 |
| :--- | :--- |
| 「… は有効期限を過ぎたため本予約を確定できません。再見積りが必要です。」・「失効（荷主承認済み）の見積りは本予約を確定できません。…」 | 仕様です（不具合ではありません）。見積りの有効期限を過ぎています。荷主の承認の後に失効した見積りの再見積りは、まだ画面で操作できません。扱いは担当者で相談してください |
| 「… は新しい見積りに置き換えられたため本予約を確定できません。最新の見積りを確かめてください。」 | 再見積りで新しい見積りがあります。最新の見積りで進めてください |
| 「… は荷主の承認がまだのため本予約を確定できません。」 | 荷主の承認を待ってください |
| 「本予約を確定できませんでした」と「営業担当者の確認: 契約条件と照合したことを確かめて、チェックを入れてください。」 | 契約条件と照合して「契約条件と照合した（営業担当者の確認）」にチェックを入れてから確定してください |
| すでに予約に使われていることと追跡番号が示される | 仕様です（不具合ではありません）。ほかの担当者が先に確定しています。示された予約の詳細を開いて確かめてください |

### Q3-2. 予約の詳細の「追跡の開始」が「処理中」のまま

| 確認すること | 対処 |
| :--- | :--- |
| 確定した直後か | 仕様です（不具合ではありません）。追跡の開始は確定の後に自動で進みます。画面は自動では変わらないので、少し待ってから開き直してください |
| 長く「処理中」のまま、または「有人確認要（担当者が確認します）」 | システム管理者にお問い合わせください |

### Q3-3. 経路の確定・実績の登録で「ほかの…が先に…を更新しました」と示された

| 確認すること | 対処 |
| :--- | :--- |
| ほかの担当者が同じ案件・追跡記録を同時に操作した | 仕様です（不具合ではありません）。最新の内容を確かめ、必要ならもう一度操作してください |

### Q3-4. 実績を登録すると既存の実績が示される（「出典（…）の実績はすでに登録されています（実績 N）。今回の入力は登録していません。」）

| 確認すること | 対処 |
| :--- | :--- |
| 同じ出典の種類と参照の実績をもう一度登録した | 仕様です（不具合ではありません）。同じ出典の実績を二重に登録しません。「実績 N を一覧で見る」で既存の実績を確かめてください |

## 4. エラーメッセージ早見表

入力欄の下とエラー要約に示される主なメッセージです。

| メッセージ | 主な画面 | 対処 |
| :--- | :--- | :--- |
| 入力してください | 各画面 | 必須の項目を入れてください |
| UN/LOCODE（国コード 2 文字 + 地点コード 3 文字、例: JPTYO）で入力してください | 見積依頼の作成、主要実績の登録 | 港の 5 文字のコードで入れてください |
| 同じ港が出発地に入っています。別の港を入力してください | 見積依頼の作成 | 目的地に出発地と違う港を入れてください |
| 過ぎているか、提出する時刻と同じです。提出する時刻より後の日時を入力してください | 見積依頼の作成（希望到着期限） | 提出する時刻より後の日時を入れてください |
| 2026-11-02 09:00 の形（日本時間）で入力してください・2026-11-01 11:30 の形（日本時間）で入力してください | 日時の入力欄（見積依頼の作成・見積りの作成・主要実績の登録） | 「年-月-日 時:分」の形で入れてください |
| いまより前の日時を入力してください | 主要実績の登録（発生時刻） | 登録する時刻より前の発生時刻を入れてください |
| 1 以上の整数で入力してください | 見積依頼の作成（個数） | 1 以上の整数を入れてください |
| 0 より大きい値で入力してください | 見積依頼の作成（総重量・容積） | 0 より大きい値を入れてください |
| 小数点以下 3 桁までで入力してください | 見積依頼の作成（総重量・容積） | 小数点以下 3 桁までにしてください |
| PDF・PNG・JPEG のファイルを選び直してください | 見積依頼の作成（書類） | PDF・PNG・JPEG のファイルを選んでください |
| 1 件 10 MB までのファイルを選び直してください | 見積依頼の作成（書類） | 10 MB までのファイルを選んでください |
| 1 行以上入力してください | 見積りの作成（料金明細） | 料金明細を 1 行以上入れてください |
| 4,000 文字までで入力してください | 審査、経路の確定 | 4,000 文字までにしてください |
| CT で始まる 14 文字で入力してください。英字の I・L・O と数字の 0・1 は使いません（例: CTABCDEFGH2345） | 追跡の照会 | 追跡番号を確かめて入れ直してください |
