# cargo-tracker ユーザーマニュアル

cargo-tracker（国際貨物の見積りから予約・追跡までを扱うシステム）を使う業務担当者のための手引きです。画面の前に座った担当者が、その場で手を動かせることを目的にしています。

本マニュアルは Release 0.1（最初の縦の流れ）の画面を対象にしています。まだ作っていない画面（「この画面は準備中です」と示される画面）は載せていません。

## 章の構成

章は、役割ごとのナビゲーションの並びに沿っています。業務の順序は [1 章 業務フロー](01-業務フロー.md) が示し、各章はそこから参照されます。

| 章 | 内容 | 主に使う人 |
| :--- | :--- | :--- |
| [はじめに](00-はじめに.md) | 読み方、表記の決まり、動作環境 | 全員 |
| [1 章 業務フロー](01-業務フロー.md) | 見積依頼から追跡の照会までの流れと、各章への入口 | 全員 |
| [2 章 ログインと共通の画面](02-ログインと共通の画面.md) | ログイン、画面の構成とナビゲーション、権限がない画面、再ログイン | 全員 |
| [3 章 見積依頼](03-見積依頼.md) | 見積依頼の作成と提出、一覧、詳細 | 荷主担当者 |

社内の担当者（営業担当者・経路設計者・追跡管理者）の章は、続けて追加します。

## 執筆の決まり（執筆者向け）

### 節のテンプレート

画面ごとに 1 節を立て、次の順で書きます。読者が実際に迷う順序です。

1. この画面でできること（業務上の目的）
2. 画面の開き方（ナビゲーションと URL）
3. 画面の説明（キャプチャと、丸数字の項目の表。丸数字は画面の上から順）
4. 操作手順（番号付き。クリックする対象は「」で囲む）
5. 注意・補足（業務ルール上の注意、エラーのときの対処、関連する画面）

各章の冒頭には、章で何をするか、対応する業務フローへのリンク、画面の開き方、画面の一覧を置きます。

### 画面のキャプチャ

キャプチャは手作業で置かず、画面の層のテストで自動で撮ります。

```bash
cd apps/cargo-tracker
./gradlew manualScreenshots
```

- 撮影の手順は `apps/cargo-tracker/src/test/resources/features/ui/manual_screenshots.feature`（`@manual`）にあります。新しい画面を撮るときは、ここに「画面 "…" を開く」「画面を "…" として撮る」の手順を足します
- 本番と同じ設定（開発用の利用者の欄がない）で撮り、データはテストが作るダミーです。実在の企業・人の情報は写りません
- ファイル名は `<章番号>-<英字の名前>.png` です。航海番号や追跡番号などはテストのたびに変わるので、撮り直すと値が変わります

### HTML のマニュアル

このマニュアルは、ER 図・JIG と同じくドキュメントサイトに HTML としても載ります（`npx gulp manual:build`。`npx gulp docs:generate` にも含まれます）。出力先は `docs/assets/manual-output/cargo-tracker/` です。
