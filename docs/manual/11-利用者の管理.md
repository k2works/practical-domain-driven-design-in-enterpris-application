# 11 章 利用者の管理

システム管理者が、利用者の一覧と詳細を確かめ、利用者の役割を確認の画面を経て付けたり外したりする手順です。役割は、荷主担当者・営業担当者・経路設計者・追跡管理者・データ責任者・カスタマーサポート・システム管理者・監査担当者の 8 つに決まっています。

画面の開き方: ログインするとこの章の一覧が開きます。ナビゲーションの「利用者」（URL: `/staff/users`）からも開けます。システム管理者だけが開けます。

| 画面 | 役割 | 節 |
| :--- | :--- | :--- |
| 利用者 | 企業と利用者と役割を一覧する | [11.1](#111-利用者) |
| 利用者の詳細 | 利用者の今の役割を確かめ、変更する役割を選ぶ | [11.2](#112-利用者の詳細) |
| 役割の変更の確認 | 変更の内容を確かめてから変更する | [11.3](#113-役割の変更の確認) |

## 11.1 利用者

### この画面でできること

- 企業と利用者と役割を一覧で確かめます
- 利用者を選んで詳細を開きます

### 画面の開き方

- ログインの後に開きます。ナビゲーションの「利用者」（URL: `/staff/users`）からも開けます

### 画面の説明

![利用者](assets/11-users.png)

| # | 項目 | 説明 |
| :--- | :--- | :--- |
| ① | 企業 | 利用者が所属する企業 |
| ② | 表示名 | 利用者の名前。押すと詳細が開きます |
| ③ | メールアドレス | ログインに使うメールアドレス |
| ④ | 利用状態 | 利用中か利用停止か |
| ⑤ | 役割 | 利用者が持つ役割 |

### 操作手順

1. 役割を変えたい利用者の表示名を押します

### 注意・補足

- 一覧は企業名・表示名の順に並びます
- 利用者の登録と利用停止は、この画面ではまだできません。後のリリースで足します

## 11.2 利用者の詳細

### この画面でできること

- 利用者の企業・メールアドレス・利用状態・今の役割を確かめます
- 付けたい役割を選び、変更の内容の確認へ進みます

### 画面の開き方

- 一覧で利用者の表示名を押します

### 画面の説明

![利用者の詳細](assets/11-user-detail.png)

| # | 項目 | 説明 |
| :--- | :--- | :--- |
| ① | 企業 | 所属する企業と、その種類（荷主企業・荷受人の企業・運用する会社） |
| ② | 今の役割 | 利用者がいま持つ役割 |
| ③ | 役割 | 変更した後に持たせる役割に印を付けます。企業の種類に付けられない役割には、その旨が添えてあります |
| ④ | 変更内容を確認する | 選んだ役割で、変更の内容の確認へ進みます。まだ変更されません |

### 操作手順

1. 変更した後に持たせる役割に印を付けます（外したい役割は印を外します）
2. 「変更内容を確認する」を押します

### 注意・補足

選び方が決まりに合わないときは、確認へ進まず、この画面の上に理由が示されます。

![役割の変更の誤り](assets/11-role-change-rejected.png)

| 示される理由 | 直し方 |
| :--- | :--- |
| 自分の役割は変更できません。ほかのシステム管理者に依頼してください。 | 自分の役割は、ほかのシステム管理者に変えてもらいます |
| 役割を 1 つ以上選んでください。 | 役割を 1 つ以上選びます |
| 今の役割から変わっていません。足す役割か外す役割を選んでください。 | 足す役割か外す役割を選びます |
| （役割）は、（企業の種類）の利用者には付けられません。 | 荷主担当者は荷主企業の利用者だけに、ほかの役割は運用する会社（A 社）の利用者だけに付けられます。荷受人の企業の利用者には役割を付けません |
| システム管理者・監査担当者と、業務データを変更できる役割（…）は併せて付けられません。 | システム管理者・監査担当者は、業務の役割（荷主担当者・営業担当者・経路設計者・追跡管理者・データ責任者・カスタマーサポート）と併せて付けられません（職務分離）。どちらかの印を外します |

- システム管理者と監査担当者は、併せて付けられます

## 11.3 役割の変更の確認

### この画面でできること

- 対象の利用者・今の役割・足す役割・外す役割・影響・実行者・元に戻す方法を確かめて、役割を変更します

### 画面の開き方

- 利用者の詳細で役割を選び、「変更内容を確認する」を押します

### 画面の説明

![役割の変更の確認](assets/11-role-change-confirmation.png)

| # | 項目 | 説明 |
| :--- | :--- | :--- |
| ① | 対象 | 役割を変える利用者 |
| ② | 今の役割・足す役割・外す役割 | 変更の内容。足す役割・外す役割がなければ「なし」 |
| ③ | 影響 | 変えた役割は、相手の次の操作から効きます |
| ④ | 実行者 | 変更するシステム管理者（あなた） |
| ⑤ | 回復手段 | 元に戻すには、もう一度役割を変更します |
| ⑥ | 変更する・戻る | 「変更する」で変更します。「戻る」で選んだ役割を残したまま詳細に戻ります |

### 操作手順

1. 変更の内容を確かめます
2. 「変更する」を押します
3. 利用者の詳細に「役割を変更しました。相手の次の操作から効きます。」と出て、今の役割が新しい役割になります

### 注意・補足

- 変えた役割は、相手がログインし直さなくても、相手の次の操作から効きます。外した役割の画面を相手が開くと「この画面を表示する権限がありません。」と示されます（[2.3](02-ログインと共通の画面.md#23-権限がありません)）
- 確認している間に、ほかのシステム管理者の変更などでその利用者の情報が先に更新されていたら、変更されず「この利用者の情報が先に更新されました。最新の内容を確かめてから、もう一度変更してください。」と示され、最新の詳細が開きます。今の役割を確かめてから、もう一度選び直してください
- 役割の変更は、操作したシステム管理者・時刻・変更前後の役割として記録されます
