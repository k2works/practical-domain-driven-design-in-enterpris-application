# はじめに

## このマニュアルについて

cargo-tracker は、荷主（貨物を送る会社）からの見積依頼を受け付け、見積りと経路を提示し、本予約を確定し、貨物の輸送を追跡するためのシステムです。このマニュアルは、cargo-tracker を使う業務担当者のための操作の手引きです。

どの画面をいつ使うかは、まず [1 章 業務フロー](01-業務フロー.md) で確かめてください。各章は、業務フローの工程から参照されます。

## 利用者の役割

cargo-tracker では、ログインした利用者の役割によって、使える画面が決まります。

| 役割 | 所属 | 主な仕事 | 本マニュアルの章 |
| :--- | :--- | :--- | :--- |
| 荷主担当者 | 荷主の会社 | 見積依頼の提出、見積りへの回答、見積りと経路の承認、予約と追跡の確認 | 3〜5 章 |
| 営業担当者 | 自社（A 社） | 見積依頼の審査、見積りの作成と提示、本予約の確定、KPI 計測記録の確認 | 6・7・10 章 |
| 経路設計者 | 自社（A 社） | 経路の候補の比較と確定 | 8 章 |
| 追跡管理者 | 自社（A 社） | 主要な実績（集荷など）の登録 | 9 章 |

## 表記の決まり

| 決まり | 例 |
| :--- | :--- |
| ボタン・リンク・入力項目・選択肢は「」で囲みます | 「提出する」をクリックします |
| 画面の場所は、ナビゲーションの項目と画面の名前で書きます | ナビゲーションの「見積依頼」→ 見積依頼の一覧 |
| 画面の項目には丸数字を振り、表で説明します。キャプチャには番号を描いていません。丸数字は画面の上から順、一覧の表は列の左から順です | ① 業務番号 |
| 状態は画面の表示のとおりに書きます | 「審査中（A 社の対応待ち）」 |
| 日時は日本時間（Asia/Tokyo）で示します。社内の画面では UTC も併記します | 2026-10-10 18:45 Asia/Tokyo（UTC+09:00） |

## 動作環境

- 最新版の Google Chrome・Microsoft Edge・Firefox・Safari のいずれか
- 画面の幅が狭いとき（スマートフォンなど）は、ナビゲーションがメニューのボタンにまとまります
- キーボードだけでも操作できます（Tab キーで項目を移り、Enter キーで決定します）

## 困ったときは

荷主の画面の下に、カスタマーサポートの窓口（平日 09:00〜18:00 Asia/Tokyo）が示されます。荷主の方は担当営業に、社内の方はシステム管理者にお問い合わせください。お問い合わせの際は、画面に示された業務番号（TR-…）や追跡番号（CT…）をお伝えください。
