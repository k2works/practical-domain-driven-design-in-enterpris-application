### 環境

この Bolt では、クラウドの実行環境で次を整えた（リポジトリは変えていない）。

- JDK 25 を apt で入れた。Gradle をロケール `C.UTF-8` で動かした（日本語のファイル名のテストの報告で失敗するため）。Maven Central の 429 は取り直した。
- Playwright 1.63 が求める Chromium 1243 は、ダウンロード元がネットワークの方針で許可されていないため、既存の Chromium 1194 を同じ場所から参照させて代用した。CI は正規の版で回る。
- dockerd が待機中に止まったため起動し直した。
- SonarQube のローカルの起動で、Elasticsearch のファイルディスクリプタの上限（この環境は 20,000 から上げられない）と、Web の heap（リポジトリの compose は 256 MB。初回のルールの登録で足りない）のため、スクラッチパッドの上書きファイルで起動時チェックを外し heap を 2 GB にした。

### ふりかえり（KPT）

- **Keep**:
  - どのステップでも Red を先にコミットし、表と画面の層は実装の前に実行して新しいテストだけが失敗することを記録できた
  - レビューの画面の指摘は、内側（業務の規則と照会）を先に Green にしてから画面の Red を記録し、最後に画面を直した。画面の Red を実行で確かめられた
  - 開発レビューで、テストが通っていても荷主が誤解する表示と、営業の行き止まりを、終了報告の前に見つけて直せた
- **Problem**:
  - 状態を変える操作（再見積り）を計画したとき、操作の最中に相手（荷主・営業）がどの画面で何を見るかを確認ポイントにしなかった。開発レビューで初めて見つかった（R-01・R-02）
  - 計画の結果の時刻を、最後のコミットでなく記録した時刻で書いた（R-05）
  - この環境の準備（JDK、ブラウザ、SonarQube）に、ステップ 6 の約 4 割を使った
- **Try**:
