# Bolt 39d3b2 終了報告 - S-17 で主要実績の内容の違う原本の隔離を採用し、採用できない隔離の理由を示す

## 承認の議題（T-36。先に確かめてほしいこと）

データ責任者が、S-17 の判断の画面で主要実績の内容の違う原本も採用できるようにしました。採用できない隔離には理由の文を示し、画面を開いた後に採用できなくなったときは判断の画面に戻して理由を示します。すべての判断を推奨のとおり承認として記録しています（Recommend 承認の指示による）。業務の判断を含むものを先頭に置きます。

## 判断と学び

- 前の Bolt で 404 にした判断を次の Bolt で覆すのは、案内の出口ができたからで、前の判断の誤りではない。「なぜ 404 にしたか」（先のないリンク）を書いておいたので、覆す根拠を確かめられた
- 骨組みは固定の値を返す形にすると、理由の分岐を Red から書ける。今の定めのまま理由を返す形だと、行が Red の時点で緑になる
