## 判断と学び

- 分ける前に外側の応答の特性のテストを足し、部品を `@Import` で本物にしておくと、分割で記録の向きを取り違えても落ちる。モックにすると、守りたい書き手そのものが消える
- 「書き手は 1 か所」と文書に書くときは、規則がそれを構造で守っているかを確かめる。パッケージの単位の規則は、同じパッケージに controller が増えると守れない
- 2 つの値（領域と誤り）を別々に渡すと、取り違えの余地が生まれる。1 つの値にまとめれば、強制の確かめも要らない
