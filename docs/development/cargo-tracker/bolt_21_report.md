### ふりかえり（KPT）

- Keep
  - 開始準備の横断検証で、開発戦略の規則（既存の集約に足す Bolt はアウトサイドイン）とのずれを着手前に見つけた。規則どおり受入シナリオから下りて、やり直しがなかった

  - 表の制約と条件付きの更新で、集約の規則を並行性に強い形でも守った
- Problem
  - テスト用のメモリのリポジトリが実体を返していたため、listener の保存の呼び出しをどのテストも守っていなかった（レビューで見つかった）
  - 「提出の記録がない」と「提出時刻より前」を同じ扱いにした。後者は再配信しても直らない（ADR-014 の考え方に反した）
  - 確認ポイント 7 で自分が決めた「3 つ目で集める」を、その 3 つ目で守らなかった
  - 運用のタスク（`sonar-local:scan`）と `documentationTest` が Windows の作業ツリーで動かなかった
- Try
  - T-61: テスト用のメモリのリポジトリは、読み出しで写しを返す（保存しなければ変わらない）。新しく作るときも既存のものを触るときも、保存を外すとテストが落ちることを確かめる（AI、次の Bolt から）
