## 判断と学び

- 判断を待つ隔離のような「まだ起きていないこと」の一覧は、既存の判断の表との `NOT EXISTS` で作れ、判断の機能（39d2）の前に一覧を出せる。縦に分けると、画面を先に見せて業務の判断を先に記録できる
- 照会専用の値はドメインの値オブジェクトの場所に置き、リポジトリが結合で返す（ドメインのポートはアプリケーションの型を返せない）
