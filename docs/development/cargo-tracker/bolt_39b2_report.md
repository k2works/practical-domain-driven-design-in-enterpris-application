## 判断と学び

- 件数を数える単位を、設計の前に決めておく。物理行とレコードは引用符の中の改行で食い違い、閉じ忘れの範囲は物理行でしか数えられない
- 誤りの種類（ファイル・行・ファイルの終わりまで）を null の有無で表すと、ありえない組み合わせを作れる。範囲を型に持たせて、コンストラクタで拒む
- 未 push のマイグレーションは、どの環境にも当たっていないので同じ版の中で直せる。push した後は新しい版にする

### ふりかえり（KPT）

- Keep: 計画の 2 つの検証で、要確認をデータ行が 0 のファイルの誤りで表せないことを実装の前に見つけた。ステップごとに `spotbugsMain` を流し、SpotBugs の指摘をステップ 7 に持ち越さなかった（T-232 が効いた）。この Bolt のサブエージェントは heredoc を 1 度も使わなかった
