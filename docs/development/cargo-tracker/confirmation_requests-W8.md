## 回答の反映（確認の場の後）

1. 回答日・回答者・状態を台帳に書く（仮 → 確認済み、または変更）。
2. 回答が仮と違った件は、影響の大きい順に Bolt を起票する（D-145 が「意図でない」なら 40-3-1）。
3. 設計文書（domain_model・ui_design・data_model・マニュアル）の仮の注を直す。
