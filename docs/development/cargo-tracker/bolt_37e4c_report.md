## 判断と学び

- 届く順 B では、先に届く DE-06 の効き目は「何もしない（警告）」なので、届かなくても結果が同じになる。届いたことそのものを確かめないと、届く順の確かめにならない
- 本物の部品を通す統合テストでも、確かめたいこと（予約が残る）と関係のない前提（追跡の開始に要る経路設計の案件）で、計画した確かめ（予約サガの完了）が成り立たないことがある。計画の段階で、確かめる値がどの部品の何に依存するかを書くとよかった
