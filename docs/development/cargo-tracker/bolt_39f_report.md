## 判断と学び

- 非同期の listener で「同じトランザクションで評価する」は、別の行の別の更新の順まで保証しない。スレッド数の設定を読めば計画の時点で確定できる前提を、実行で確かめるとしない
- 誤った採用の影響は、書き手の後ろに反応が増えるたびに広がる。39e まで元に戻せた操作が、39f で戻せなくなった。反応を足す Bolt では、前の Bolt の「直し方」がまだ通じるかを確かめる
