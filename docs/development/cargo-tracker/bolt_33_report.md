## 判断と学び

### 既知の課題（後に持ち込む）

- 送信は at-least-once（送った後、コミットの前に落ちると 2 通目が出ることがある。ADR-017）
- 応答時間の差、発信元ごとの抑止と監査の発信元、爆撃の上限、SES と送信元の認証、保持の期間、再試行とバウンス（#49）
- W9 の宛先のモデル（ADR-017 の既知の課題）
- トークンを URL の path に入れるので、A-06 を作る 33a で Referer・アクセスログへの露出を扱う（GET で受けて session に移し、トークンのない URL へ移す案など）
- `notification` の `findByEventIdAndRecipient` は本番のコードから呼ばれていない（調査とテストに使う）
- `SchemaCommentIntegrationTest.BUSINESS_SCHEMAS` に `tracking` が入っていない（Bolt 33 の開始準備で見つけた。別の小さな直し）
- デモ環境の Config Vars の反映は人の作業（議題 6）

## 次の Bolt
