## 判断と学び

- スキーマだけの Bolt でも、テストのデータはドメインの規則に従う形で書く。制約が許すことと、業務として正しいことは別で、テストのデータは仕様の例として読まれる
- 共有の DB の統合テストは、1 本の接続でロールバックすると、ほかのテストの前提（承認済みの情報源が 0 件など）を汚さない
