# Bolt 37e4 終了報告 - US-07 AC5 の出発済みの経路（D-88 の判定・理由・文言・マニュアル）

## 承認の議題（T-36。先に確かめてほしいこと）

割り当てた経路の最初の区間が出発した見積りについて、荷主は見積りと経路を承認できず、営業担当者は本予約を確定できないようにしました（D-88）。境界は経路設計の確定の出発済み（`ALREADY_DEPARTED`）と同じで、出発予定が判定の時刻と同時刻か前なら出発済みです。6 つの画面（C-04・C-17・S-02・S-04・S-09 と、C-04 のもう一度の承認）に理由と次の行動を示し、荷主の画面には社内の語（区間・出発済み・再設計要）を出しません。出発済みは時刻だけで画面に出るので、マニュアルとキャプチャもこの Bolt に入れました（見本とデモは Bolt 37e4b）。

## 判断と学び

- 境界の式を 2 か所に書くと、片方だけ直す誤りが入りうる。照会の行（読み取りモデル）も、ドメインの値の静的な操作で同じ境界を使える
- 照会の SQL で「最初の区間」を番号の定数で選ぶと、集約の「最初」と意味が分かれる。集約と同じ決め方（最小の番号）にした
- 計画の確認ポイントで文言を先に決めたので、実装とマニュアルは文言を写すだけで済んだ
