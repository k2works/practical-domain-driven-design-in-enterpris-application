## 判断と学び

- 画面の「案内」を直すとき、同じ画面のほかの段落（見積りの節）にも同じ約束の文があった。案内の選び方の単体テストだけでは見えず、画面を描くテストで初めて分かった
- Thymeleaf の HTML の注（`<!-- -->`）は応答に残る。荷主の画面のテンプレートに社内の語を書くと、そのまま荷主に届く
- 設計の文書を先に書くと、計画の表の矛盾（S-04 の承認済みの失効の案内）が実装の前に見つかった
