| 1 | **表示名の規則**: 前後から Java の空白と Unicode の空白（NBSP・U+202F・U+2007 など）を除いた後に、次のどれかに当たる名前を拒む。<br>・空<br>・200 コードポイントを超える<br>・制御文字を含む<br>・書式文字（U+202E・U+200B・U+FEFF・国旗のタグなど）を含む<br>・行と段落の区切り（U+2028・U+2029）を含む<br>絵文字の ZWJ の連なりも拒むことになる（受け入れた）。既に登録した利用者の名前は変えない | `UserRegistrationService` |

## 判断と学び

- 新しい値をパラメーター化のテストに足すときは、同じ形のテストを作らず既存のテストに足す。SonarQube は、同じ中身の 2 つのメソッドを重複として数える
- 「準備にあることを先に確かめる」（T-106）は、自分で書いたリストを確かめても意味がない。確かめるのは、変異が落ちるための前提（ここでは規則の値）
- 範囲外の状態を示さない照会では、ない企業でも同じ読み出しをすることまでテストで見張る
