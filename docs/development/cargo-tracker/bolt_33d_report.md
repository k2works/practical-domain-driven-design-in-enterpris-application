## 判断と学び

- 守りのテストを先に足しても、比べる値が定数と同じ値でテンプレートにも残っていると、「定数から描いた」ことは確かめられない。変異は「値を変える」だけでなく「描く仕組みを外す」でも入れる
- 形を確かめる値オブジェクトは形の知識を持つので、「形の知識をどこに置くか」は値オブジェクトを足すと決めた時点で決まっていた。計画の段階で、値と集約の依存の向きから置き場所を確かめておけば、実装で変えずに済んだ
- スクラッチパッドに前の Bolt の同じ名前のスクリプトが残っており、書き込みに失敗したまま古いスクリプトを実行して、無関係なテスト 4 つを書き換えた。作業前に変更のなかったファイルなので HEAD から戻した。以後は Bolt の接頭辞（`b33d_`）を付けた名前にした
