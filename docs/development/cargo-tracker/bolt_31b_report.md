## 判断と学び

- 一意制約の違反を「同じトランザクションで捕まえない」規則と、「結果を 1 つの経路にする」ことは両立する。トランザクションをサービスの内側に持ち、外側で受ければよい。最初は規則に合わせて画面の層で受け、結果の経路が分かれた。規則に合わせるとき、責務の置き場所を動かしていないかを確かめる。
- 期限のある画面は、期限の長さでなく時刻で示すほうが、再読み込みや画面の移動で誤解されない。テクニカルライターの観点（T-90）がなければ見落としていた。
- session に平文を置かないことの確かめは、「ないこと」だけでなく「あるべきものがあること」（暗号文）を一緒に確かめないと、属性そのものが置かれていない誤りで空振りする。
