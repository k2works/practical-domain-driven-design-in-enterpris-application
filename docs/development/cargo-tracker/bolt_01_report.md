## 判断と学び

### 設計への反映（本 Bolt で反映した）

- **UI 設計に URL の決まりを追記した**: `/customer/transport-requests/new`・`/customer/transport-requests/{id}/submitted`・`/staff/kpi-observations`（仮）。計画の「注」の対応
- **バックエンドアーキテクチャに追記した**: ドメインイベントの `domain.events` は Spring Modulith の名前付きインターフェースとして公開する。MyBatis の型ハンドラーなど技術的な部品は基盤（`platform`）モジュールに置き、設定を通してだけ使う
- **開発戦略の品質チェックのコマンドを実際のものにした**
