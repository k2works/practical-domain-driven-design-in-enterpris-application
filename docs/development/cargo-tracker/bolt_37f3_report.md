## 判断と学び

- 社内と荷主で語を分けると、共通の部品（経路の表）はどちらかに寄せることになる。読み上げの名前は荷主に合わせ、社内にも「航海」を使うと決めたので、その例外をシステムメタファーの注に書いた
- 「ないこと」の確かめは、どの画面で確かめるかを受入条件の行ごとに数えないと漏れる（C-10 には足したが、C-04・C-17 に足し忘れた）
