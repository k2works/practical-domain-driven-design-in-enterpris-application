## 初稿で置く制約

- MVP は予約、見積り、経路設計、予定と主要実績による基本追跡を対象とする。
- MVP の貨物種別は一般貨物に限定し、危険物・冷凍貨物・その他特殊貨物は後続段階へ送る。（2026-09-30、human:kakimomokuri）
- 本予約前は輸送要求版を自由に更新・取下げ、本予約後から集荷前は営業承認付きで変更・取消し、集荷後は通常処理を禁止して有人例外対応へ送る。（2026-09-30、human:kakimomokuri）
- MVP の本予約は荷主担当者 1 名の承認と営業担当者の BR-01 確認で確定し、荷主内の入力者・承認者分離は後続段階へ送る。（2026-09-30、human:kakimomokuri）
- 荷主担当者は予約単位で荷受人を招待・取消しし、到着予定・現在状態・主要実績・最終更新時刻だけを開示する。取消しは既存 session の次回照会へ即時反映する。（2026-09-30、human:kakimomokuri）
- MVP の有人引継ぎは受付番号、担当、優先度、回答期限、次回更新日時、状態、顧客回答履歴を持ち、未受領時は上位の運用責任者へ escalation する。（2026-10-01、human:kakimomokuri）
- 見積りは本予約確定の commit 時刻が有効期限より前の場合だけ有効とし、同時刻以後は失効とする。時刻は UTC で保存し、利用者のタイムゾーンと UTC offset を明示して表示する。（2026-10-01、human:kakimomokuri）
- 経路候補は到着予定時刻が希望到着期限以前、かつ各接続時間が必要最小接続時間以上の場合に日時制約へ適合する。経路承認の commit 時点と参照外部情報版で判定し、承認後に不適合となった場合は予約を自動取消しせず再設計要とする。（2026-10-01、human:kakimomokuri）
- 外部原本の冪等性キーは提供元・原本種別・外部 ID・外部版とする。同一キー・同一 payload は重複、異 payload は隔離し、復旧は停止期間の全原本の分類、件数照合、手動情報との差異確認が完了した時点とする。（2026-10-01、human:kakimomokuri）
- 初期パイロットの Must は US-01〜US-04、US-06、US-07、US-09、US-11、US-12、US-14、US-16、US-18、US-20 とする。US-05、US-08、US-13、US-15、US-17 は本格展開前の Should、荷主・有人窓口で代替できる US-10、US-19 は Could とする。（2026-10-01、human:kakimomokuri）
- パイロットは選定航路の一般貨物全件を母集団とし、開始前 4 週間を基準、開始後 4 週間または完了予約 30 件の遅い方を観測期間とする。KPI-01・KPI-02 の改善と重大ガードレール 0 件で継続し、未達は期限付き延長、重大違反は中止とする。（2026-10-01、human:kakimomokuri）
- 主要業務フローは WCAG 2.2 AA を目標とし、キーボード操作、フォーカス、ラベル、色非依存、エラー回復を横断契約とする。影響の大きい操作は対象・状態・変更・影響・実行者を示して事前確認する。（2026-10-01、human:kakimomokuri）
