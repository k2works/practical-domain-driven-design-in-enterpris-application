    Bolt 37e 終了報告 - US-07 AC5 の見積りの側（割り当てた経路の再設計要の印、荷主の承認と本予約の判定、見積りの公開 API）¶

    承認の議題（T-36。先に確かめてほしいこと）¶

    計画は 2026-10-22 に承認を受けた（ebba74d61。確認ポイント 1〜10 を推奨のとおり。データベースのマイグレーション 1 つを含む）。承認ゲートは計画と終了報告なので、ステップ 1〜6 は止めずに進めた。打ち切り（ADR-018 の守りが崩れる、既存のテストの期待値が変わる、区間の表も変える、層の規則が置き場所を拒否する）には当たらなかった。下の 1〜2 は開発レビューを受けて計画から変えた点、3 は計画の約束を守れなかった点で、事後に確かめてほしい。

    # 確かめてほしいこと AI の判断の根拠 見る場所
    1 計画からの変更: 経路版で見積りを引く照会はセッションのキャッシュを使わない（flushCache="true"）。入力ポートは同じトランザクションで照会し直して、ほかのトランザクションが後から保存した見積り（再見積りの新しい見積り）を拾う。MyBatis の既定（セッションの中で同じ引数の select は 2 度目をキャッシュから返す）では、照会し直しが更新の有無に頼って働くので、毎回データベースを見るようにした。この振る舞いを確かめるテストはない（同じトランザクションの中でほかのトランザクションのコミットを起こせない）。37e2 の listener を入れるときに、PostgreSQL の統合テストで届く順 C を起こせるか確かめる 開発レビュー（アーキテクト）M-1 QuotationMapper.xml の selectIdsByAssignedRoute
    2 計画からの変更: 荷主承認待ちに印が付くと、期限の後も出口がない。計画は「期限内の承認済みは期限まで出口がない」としていたが、荷主承認待ちは時刻に関係なく再見積りできない今の規則（D-86）のため、期限の後も出口がない。domain_model・US-07 の既知の制限を書き分け、集約のテストの行 14 に期限の後の荷主承認待ちを足した 開発レビュー（テスター）M-5 QuotationRouteRedesignTest の行 14、domain_model の状態遷移の注
    3 TDD の Red の見方: ステップ 2〜5 の Red は、まずテストのコンパイルの失敗（型と操作がない）で見て、次に型と空の操作だけを作り、期待の値の誤りで落ちることを見てから中身を作った（Bolt 37d2 の Problem への手当て）。開発レビューの後に足したテスト（再見積りの INSERT、行 20）は今のコードで通る守りで、INSERT の列を落とす変異で前者が落ちることを確かめた。行 20 は今の穴を固定する特性テストで、37e2 で期待値が変わる Bolt 37d2 の Try ステップ 3〜5

    デモ項目¶

    本番で印を付ける入口（DE-06 の listener）は Bolt 37e2 なので、利用者に見える振る舞いは変わらない。画面も変えていないので、デモの動画・キャプチャ・マニュアルは変えていない（計画の確認ポイント 7・10）。W6 のデモ項目「再設計要の経路の拒否」は Bolt 37e3 で見せる。

    判断と学び¶

    • 集約の値（AssignedRoute）に事実の写し（印）を持たせると、写す操作（再見積り）が増えずに済んだ。印を見積りの状態にしていたら、状態の組み合わせが倍になり、再見積りにも引き継ぎのコードが要った
    • 照会し直しで正しさを守る設計は、永続化の層のキャッシュの振る舞いに頼ることになる。テストはメモリ上のリポジトリだけで、データベースの振る舞いはコードとレビューでしか確かめられなかった
    • 開発レビューで、INSERT の経路だけが確かめられていないと分かった。変異は「自分が書いた分岐」から選びがちで、写しの列（保存の文）を落とす変異を計画に入れていなかった

    • Keep
    • 開始準備で Bolt を 3 つに分け、2 つの検証で出発済みの判定（D-88）が利用者に見えることを着手の前に見つけ、37e3 に移せた

    • 届く順の表（A〜E）を計画に置き、テストで C・E を起こせた

    • 計画の変異に、保存の文の列を落とす変異が入っていなかった
    • シェルの heredoc がまとまったファイルの作成で解釈されず、1 回の作成がまるごと失敗した
    • Try

    • T-181: 列を足す Bolt の変異には、挿入・更新・読み戻しのそれぞれから列を落とす変異を入れる
