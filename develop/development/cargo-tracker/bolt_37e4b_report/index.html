    Bolt 37e4b 終了報告 - US-07 AC5 の出発済みの経路の見本とデモ¶

    承認の議題（T-36。先に確かめてほしいこと）¶

    割り当てた経路の最初の区間が出発した見積依頼の見本を 2 件、開発データに入れました。デモ環境と dev で、Bolt 37e4 で入れた理由と次の行動を見られます。W6 のデモ項目「出発済みの拒否」の動画 2 本も撮りました。本体のコード・スキーマ・画面の文言・マニュアルは変えていません。

    # 確かめてほしいこと 見る場所
    1 開発データの見本 2 件（データベース）。TR-2026-0911・RC-2026-0908 は荷主承認待ちのまま、TR-2026-0912・RC-2026-0909 は荷主の承認の後に、最初の区間が起動した日の前日に出発した。どちらも経路版は確定済みで、再設計要の印は持たない。デモ環境に入る（起動のたびに初期状態に戻る） db/dev-data/V20261023200900__seed_dev_sample_route_departed.sql、DevSampleDataSmokeTest
    2 区間の写しと航海の予定の食い違い（開始準備の決定 (2)）。写しの出発は起動した日の前日、航海 DEMO-101 の予定は起動した日の 5 日後のまま。技術リスクの表に 1 行足し、W7 の評価の入口をつなぐ Bolt の開始準備の確認の項目にした。手順書と README にも、見本のための値だと書いた release_plan.md の技術リスクと W7 の行、heroku_demo_setup.md、apps/cargo-tracker/README.md
    3 計画の誤りを 1 つ直した。計画はデモ環境を PostgreSQL と書いていたが、デモ環境も H2（MODE=PostgreSQL）のインメモリで、dev-data を PostgreSQL に読み込む道はない（開発レビューで分かった）。計画の H1 とステップ 5 を直した。PostgreSQL だけの部分一意インデックス（ux_quotation_active・ux_route_version_confirmed）を見本が満たすことは、開発レビューで値を確かめた 計画の更新履歴

    計画は 2026-10-23 に承認を受けた（6efc9fc5d）。計画から変えたのは議題 3 の 1 点。変異は計画の 6 つ（V1〜V6）を替えずに当て、開発レビューで足した検査の 3 つ（W1〜W3）も当てた。

    Red の確かめ¶

    見本の検査を先に書き、見本がないことで 12 本が落ちる（値がない、件数が足りない、番号がまだ 911）のを見てから見本を入れた。既存の見本が出発済みでない陰性の対照は、見本の前から緑だった（既存の見本の出発は起動の後）。

    判断と学び¶

    • 計画の前提（デモ環境のデータベース）を手順書の図で確かめずに書いた。開発レビューで設定のファイルから分かった。前提は設定のファイルで確かめる
    • 「今の振る舞いのまま」と手順書に書く見本は、その振る舞いを固定する検査を置かないと、振る舞いが変わったときに手順書が古くなる
    • 見本の値の決定（経路方針の出発を区間の出発より前にする）は、検査で守らないと前例の値に戻されても気づけない
