S-24 予約の詳細の「追跡の開始: 処理中／完了」は、自動の更新・通知領域を作らず、利用者が画面を更新して確かめる形に決めた（Bolt 25、2026-10-09）。自動の更新は「社内の画面の共通の部品の Bolt」に回した。S-24 に後から戻る入口（S-10 予約一覧）は Bolt 25b。

**Why:** Bolt を半日以内に収めるため、また処理中を完了と出さない（ADR-015）ことを優先したため。

**How to apply:** 非同期の状態を出す画面のレビューでは、(1) 案内の文が「自動で表示する」と「手で更新する」を混ぜていないか、(2) 処理中のまま終わらない場合（デモ環境の Bolt 23・24 の予約、W8 の滞留）の出口があるか、(3) 他の画面（荷主 C-04 の「予約確定済み（追跡の開始の準備中）」など）の文言が事実とずれていないか（T-69）を見る。関連: [[t-69-wording-matches-fact]]
