Bolt 34f（2026-10-18）の S-20 詳細のレビューで見つけた点。

- エラー要約のリンクが「表示名: 文言」の形でない（S-09・S-13 は形どおり。共通部品「エラー要約」）。詳細は layout に `~{}` を渡すので要約へフォーカスも移らない（role="alert" の読み上げだけ）
- 要約のリンク先が fieldset（`#roles`・`#suspension-reason`）。フォーカスできない要素なので、短い画面では押しても何も動いて見えない。前例の案は最初の入力へ
- 「付ける役割」は結果の集合（今持つ役割も印が付く）なのに「付ける」は追加に読める。確認の画面の「足す役割」と近い。「変更した後の役割」などの案
- マニュアル 00 章の決まり「丸数字は画面の上から順」に 11.2 の ④ 利用状態が外れている（画面では今の役割より上）
- 企業の種類の拒否（UNFIT_FOR_COMPANY）は field=true で #roles へリンクするが、荷受人の企業の詳細にはフォームがない（画面を経ない送信でだけ起きる）

**Why:** 画面の名前を変える Bolt でも、要約の形・リンク先・マニュアルの番号は前例と照らさないと外れたまま残る。
**How to apply:** S-20 や同じ形の詳細の画面のレビューでは、まずこの 5 点を見る。関連: [[project-form-review-checklist]]
