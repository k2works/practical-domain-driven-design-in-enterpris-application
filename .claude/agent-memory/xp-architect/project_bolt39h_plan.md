Bolt 39h の計画（2026-11-12、draft・承認待ち）で推奨したこと: 39h を 39h（取込で差異に分類し S-16 で示す）・39h2（S-17 で一覧・却下）・39h3（外部版をまたぐ比べと古い隔離の採用の警告）・39h4（G-06・照合表・W7 動画・#18）に分ける。差異は却下だけ、採用値を作らない、DE-31 を足す、スキーマは変えない。

**Why:** 初稿は比べる相手を公開した時刻の順の採用値 1 つにし、逆転を取得時刻で判定していた。システムの時計で選んだ相手と提供元の時計で比べると、人が古い外部版の隔離を採用した後に届いた中間の版を自動で採用してしまう（AC5 違反）と横断検証で指摘された。逆転は「最後に取得した採用値」、矛盾は「公開した時刻の順の採用値」に分けた。また追跡番号の違いを差異にすると D-115・D-120 の自動で届く道が閉じる後退がある（【前の決定の変更】(26)）。

**How to apply:** 39h2〜39h4 の開始準備やレビューで、比べる相手の 2 つの時計を混ぜていないか、差異の外部原本（採用値のない外部原本）の基準の意味が ED-INV-02 と食い違っていないかを確かめる。承認の結果は release_plan の 39h の行と台帳 D-141〜D-146 で確かめる（このメモは承認前の推奨）。[[project-bolt39g4c-plan]]
