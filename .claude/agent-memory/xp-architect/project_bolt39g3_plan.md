Bolt 39g3 は採用の実績で最新の到着見込みと最終取得時刻を導き、`withMilestones` の 1 か所で導出して UPDATE で保存する形にした（現在状態の前例）。鮮度超過（FRS-02）と航海の採用値（DE-12）で動く見込みは 39g4 に分ける提案。

**Why:** FRS-02 は「次の予定の実績」「最後に取り込んだファイルの取得時刻（外部データが持つ）」の読み方、確認中にするか読むときに示すか（定期の処理）、S-11 の一覧で示す置き場所（一覧は集約を組み立てない → スキーマか照会増）の 3 点が未決。

**How to apply:** 39g4 の開始準備ではこの 3 点と、実績の遅れと航海の新しい到着予定の優先を必ず諮る。既存の行は補正していないので配備前に `last_acquired_at` NULL の件数を確かめる。[[project-bolt39gc-plan]]
