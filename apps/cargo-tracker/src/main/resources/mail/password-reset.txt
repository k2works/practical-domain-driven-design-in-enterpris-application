cargo-tracker で、このメールアドレスの password の再設定の依頼を受け付けました。

次のリンクを開いて、新しい password を設定してください。
[(${resetUrl})]

このリンクの有効期限は [(${expiresAt})]（依頼から 30 分）です。リンクは 1 回だけ使えます。
もう一度依頼すると、このリンクは使えなくなります。
新しい password を設定した後は、新しい password と認証アプリのコードでログインし直してください。

この依頼に心当たりがない場合は、このメールを無視してください。
リンクを開かなければ、password は変わりません。
心当たりのないメールが続く場合は、荷主の方は担当営業に、社内の方はシステム管理者にお知らせください。
