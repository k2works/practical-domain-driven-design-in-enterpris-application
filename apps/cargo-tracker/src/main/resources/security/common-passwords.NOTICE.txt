よく使われる password の一覧（SEC-05。Bolt 33a）

common-passwords.txt は、password の再設定（A-06）で新しい password が「よく使われる password」に当たるかを照合するための一覧です。

出典
  SecLists（https://github.com/danielmiessler/SecLists）
  Passwords/Common-Credentials/xato-net-10-million-passwords-1000000.txt
  取得したコミット: c205c36a445bff37f8e58a9ec829105cd4975c58（2026-10-15 に取得）
  元のデータ: xato.net の Mark Burnett による 1,000 万件の password の集計の上位 100 万件

抜き出し方
  - UTF-8 として読めない行を除く
  - 12 文字以上 64 文字以下（code point）、かつ UTF-8 で 72 バイト以下の行だけを残す（SEC-04 の方針に当たらないものは照合しても意味がない）
  - 前後に空白のある行と、制御文字を含む行を除く
  - 小文字にして重複を除き、並べる（照合は大文字小文字を区別しない）
  結果: 46,146 語

更新の手順
  上の条件で新しいコミットから作り直し、このファイルの「取得したコミット」と語数を直す。
  一覧を読めない・空のときは、アプリは起動しない（BundledCommonPasswordList）。
